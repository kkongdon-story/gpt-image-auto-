Cardnews Studio 무설치 버전 사용법

1. 받은 ZIP 파일을 새 폴더에 완전히 풉니다.
2. Lite는 Cardnews Studio Lite.exe, Pro는 Cardnews Studio Pro.exe를 실행합니다.
3. resources, locales 등 주변 폴더와 파일을 삭제하거나 EXE만 다른 위치로 옮기지 마세요.
4. 바탕화면 바로가기가 필요하면 실행 EXE의 바로가기를 만드세요. 원본 EXE를 폴더 밖으로 이동하지 마세요.
5. 업데이트할 때는 실행 중인 앱을 종료한 뒤 새 무설치 폴더 전체로 교체하세요.

사용자가 추가한 배경, 영상, 폰트와 작업 기록은 앱 폴더가 아니라 Windows 사용자 데이터 폴더에 저장될 수 있습니다.
무설치 폴더만 삭제해도 사용자 데이터가 남을 수 있으므로 필요한 결과물을 먼저 백업하세요.

Windows SmartScreen이 표시되면 파일 출처와 공식 SHA-256 값을 먼저 확인하세요.
