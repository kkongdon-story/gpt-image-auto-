Template Pack v1

꽁돈 카드뉴스 GPTs 템플릿팩 제작 가이드

레퍼런스 캐러셀 이미지를 GPTs가 분석해 앱에서 편집 가능한 템플릿팩 ZIP과 글자 제거 배경 이미지를 만들도록 설계하는 문서입니다.

Purpose

목표는 원본 이미지를 그대로 앱 안에서 OCR하거나 합성하는 것이 아닙니다. GPTs가 외부에서 레이아웃, 색상, 장식, 배경을 분석하고, 앱은 검증된 JSON과 이미지 에셋을 받아서 카드뉴스를 편집 가능한 덱으로 재구성합니다.

양식 관리
문구, 카드 수, 배지, 배경, 레이어 위치를 다룹니다.
스타일 관리
색상, 폰트, 분위기, 강조색, 테두리와 크롬을 다룹니다.

Quality-first workflow

여러 장의 캐러셀을 한 번에 ZIP으로 만들라고 하면 배경 이미지가 300px 안팎의 단순 도형으로 떨어지고, template.json도 placeholder 위주로 생성될 수 있습니다. GPTs는 반드시 분석, 카드별 배경 생성, 사용자 승인, JSON 작성, ZIP 조립 순서로 움직여야 합니다.

  1. 분석만 먼저: 카드 수, 카드별 역할, 레이아웃, 색상, 장식, 텍스트 구조를 표로 정리합니다.
  2. 카드별 생성: clean background는 한 번에 여러 장 만들지 않고 카드 1장씩 만듭니다.
  3. 승인 후 진행: 각 카드 배경이 승인되기 전에는 다음 단계로 넘어가지 않습니다.
  4. ZIP 금지: 모든 카드 배경이 승인되기 전에는 최종 ZIP을 만들지 않습니다.
  5. JSON 작성: 승인된 배경 파일명과 실제 카드 역할에 맞춰 template.json을 만듭니다.
  6. ZIP 조립: 모든 배경과 JSON이 확인된 뒤에만 최종 ZIP을 만듭니다.

Inputs

  • 레퍼런스 이미지 1장 또는 여러 장의 캐러셀 캡처
  • 선택 입력: 카드 주제, 브랜드 가치관, 원하는 문체, 금지할 표현
  • 선택 입력: 유지할 장식 요소와 단순화해도 되는 요소
  • 선택 입력: 카드 장수. 없으면 레퍼런스 이미지 수를 우선합니다.

Text removal background instructions

GPTs는 레퍼런스 이미지를 그대로 복제하지 말고, 앱에서 텍스트를 다시 얹을 수 있도록 모든 글자, 숫자, 로고성 문구를 제거한 깨끗한 배경을 생성해야 합니다.

  • 텍스트가 있던 영역은 주변 질감과 색을 자연스럽게 복원합니다.
  • 배경에 남겨도 되는 것은 비언어 장식, 추상 패턴, 단순 도형, 사진 배경입니다.
  • 상표, 유료 캐릭터, 타인의 고유 로고는 제거하거나 충분히 다른 일반 장식으로 바꿉니다.
  • 파일명은 backgrounds/card-01-clean.png처럼 카드 번호를 맞춥니다.

Template-pack JSON schema

템플릿팩은 ZIP 루트의 template.json과 backgrounds/, assets/ 폴더로 구성합니다. 이미지 경로는 ZIP 루트 기준 상대 경로만 허용됩니다. 

{
  "schema": "kkongdon.cardnews.template-pack.v1",
  "name": "Black Yellow Recruit",
  "style": {
    "name": "Black Yellow",
    "usesPhoto": true,
    "pageBackground": "#111111",
    "textBackdrop": "rgba(0,0,0,0)",
    "chromeBackdrop": "rgba(0,0,0,0)",
    "ink": "#ffffff",
    "inkSub": "#f5f5f5",
    "inkMuted": "#d6d6d6",
    "accentDefault": "#ffd23c",
    "badgeBackground": "#ffd23c",
    "badgeInk": "#111111",
    "fontTitle": "\"Pretendard\", \"Noto Sans KR\", sans-serif",
    "fontBody": "\"Pretendard\", \"Noto Sans KR\", sans-serif",
    "defaultDim": 0.42
  },
  "chrome": {
    "header": "MONEY NOTE",
    "footer": "kkongdon_story",
    "pageFormat": "{n} / {total}"
  },
  "cards": [
    {
      "type": "cover",
      "backgroundImage": "backgrounds/card-01-clean.png",
      "badge": "looking for",
      "title": "모집 타이틀",
      "subtitle": "함께 성장할 사람을 찾습니다.",
      "layers": [
        { "kind": "image", "image": "assets/eye-mark.png", "x": 70, "y": 8, "width": 16, "height": 12 },
        { "kind": "line", "x1": 74, "y1": 84, "x2": 96, "y2": 84, "thickness": 3, "color": "#ffffff" }
      ]
    }
  ]
}

Style JSON schema

스타일 JSON은 카드 문구를 바꾸지 않습니다. 색상, 폰트, 배경 분위기 같은 시각 규칙만 바꿉니다. 

{
  "name": "Warm Editorial",
  "usesPhoto": true,
  "pageBackground": "#f6f1e8",
  "textBackdrop": "rgba(255,255,255,0)",
  "ink": "#151515",
  "inkSub": "#3d3d3d",
  "inkMuted": "#6d6d6d",
  "accentDefault": "#b65f32",
  "badgeBackground": "#151515",
  "badgeInk": "#ffffff",
  "fontTitle": "\"Pretendard\", \"Noto Sans KR\", sans-serif",
  "fontBody": "\"Pretendard\", \"Noto Sans KR\", sans-serif",
  "defaultDim": 0.18
}

Asset naming rules

  • template.json은 ZIP 루트에 둡니다.
  • 깨끗한 배경은 backgrounds/card-01-clean.png 형식으로 둡니다.
  • 눈알, 스티커, 테이프 같은 장식 이미지는 assets/eye-mark.png처럼 둡니다.
  • 허용 확장자는 .png, .jpg, .jpeg, .webp입니다.
  • 절대 경로, .., 중복 파일명, 실행 파일 확장자는 사용하지 않습니다.

Quality rules

  • 읽고 수정해야 하는 글자는 반드시 cards[]의 텍스트 필드로 둡니다. 즉, editable text는 배경 이미지에 굽지 않습니다.
  • 정방형 배경은 1080x1080, 세로 4:5 배경은 1080x1350을 기본으로 합니다.
  • 300px 안팎의 저해상도 배경, 단색 도형만 있는 배경, 카드 1 제목 같은 placeholder JSON은 실패로 간주합니다.
  • 단순한 선, 도형, 박스, 텍스트 박스는 앱 레이어로 재현합니다.
  • 복잡한 장식이나 사진 배경은 글자를 제거한 배경 이미지로 둡니다.
  • 원본과 같은 분위기를 목표로 하되, 타인의 고유 자산을 정확히 복제하지 않습니다.
  • 가독성이 떨어지면 장식 정확도보다 텍스트 영역과 여백을 우선합니다.

Safety/copyright caution

이 워크플로우는 합법적으로 사용할 수 있는 레퍼런스에서 구조와 분위기를 참고하기 위한 것입니다. 원본 저작물의 캐릭터, 로고, 일러스트, 유료 템플릿 장식을 그대로 재배포하는 용도로 사용하지 마세요. 필요하면 색상, 도형, 배치, 장식을 충분히 바꿔 새 템플릿으로 만듭니다.

Example GPTs instructions

당신은 꽁돈 카드뉴스 템플릿팩 제작 GPTs입니다.
사용자가 카드뉴스 레퍼런스 이미지 1장 또는 여러 장을 올리면 Cardnews Studio Lite/Pro에서 불러올 수 있는 템플릿팩을 만듭니다.

작업 순서:
1. 첫 응답에서는 ZIP을 만들지 말고 카드별 분석표와 제작 계획만 제공합니다.
2. 여러 장이면 clean background를 한 번에 만들지 말고 카드 1장씩 생성합니다.
3. 각 카드 배경은 사용자가 승인한 뒤 다음 카드로 넘어갑니다.
4. 모든 배경 승인 후에만 template.json을 작성합니다.
5. template.json 승인 후에만 kkongdon-template-pack.zip을 조립합니다.

품질 기준:
- editable text는 배경 이미지에 굽지 않고 template.json의 cards[] 필드에 넣습니다.
- 배경 이미지는 정방형 1080x1080 또는 세로 4:5 1080x1350을 기본으로 합니다.
- 배경에는 제목, 본문, 숫자, 페이지 번호, 브랜드명, 로고성 문구가 남아 있으면 안 됩니다.
- 프레임, 종이 패널, 추상 패턴, 비언어 장식은 유지할 수 있습니다.
- template.json에는 카드 역할이 드러나는 편집 가능한 한국어 문구를 넣고 placeholder만 남기지 않습니다.
- 저작권이 있는 고유 캐릭터, 로고, 상표는 일반화하거나 제거합니다.
- 최종 결과는 kkongdon.cardnews.template-pack.v1 schema의 template.json과 backgrounds/, assets/ 폴더 구조입니다.

Lite/Pro import steps

  1. 앱을 열고 디자인 탭으로 이동합니다.
  2. 양식 관리에서 템플릿팩 ZIP 불러오기를 누릅니다.
  3. GPTs가 만든 ZIP 파일을 선택합니다.
  4. 미리보기에서 배경, 제목, 배지, 본문, 장식 레이어가 들어왔는지 확인합니다.
  5. 문구는 콘텐츠 탭에서 수정하고, 색상/폰트는 스타일 관리에서 수정합니다.
  6. Lite는 템플릿팩과 수동 편집을 사용할 수 있고, AI/벌크 생성은 Pro에서만 사용할 수 있습니다.
