Cardnews Studio 배포 전 최종 체크리스트

[현재 PC 자동 검증]
[ ] Lite 설치 EXE가 설치되고 실행되는가
[ ] Pro 설치 EXE가 설치되고 실행되는가
[ ] Lite/Pro에서 4:5 PNG가 1080×1350으로 생성되는가
[ ] 설치 제거 후 격리 설치 폴더가 남지 않는가
[ ] 무설치 Lite/Pro가 새 사용자 프로필로 실행되는가
[ ] package-security.json이 PASS인가

[다른 PC 또는 깨끗한 Windows 가상머신]
[ ] 기존 Cardnews Studio, Node.js, 개발 도구가 없는 Windows 10/11에서 설치되는가
[ ] 첫 실행 시 흰 화면이나 앱 선택 창이 나타나지 않는가
[ ] 기본 프리셋과 기본 폰트가 보이는가
[ ] 1:1, 4:5, 9:16 PNG가 정확한 크기로 생성되는가
[ ] 사진과 영상 파일을 추가하고 다시 열 수 있는가
[ ] MP4 영상이 1080×1920으로 생성되고 재생되는가
[ ] 제거 프로그램이 정상 작동하는가

[배포 자료]
[ ] 사용자에게 Lite 또는 Pro 중 필요한 설치 파일 하나만 전달했는가
[ ] 해당 버전의 HTML 사용설명서를 함께 전달했는가
[ ] SHA256SUMS.txt의 값을 공식 게시글 또는 별도 메시지에도 게시했는가
[ ] 무설치형은 EXE 하나가 아니라 ZIP 또는 win-unpacked 폴더 전체를 전달했는가
[ ] 코드 서명이 없어 SmartScreen이 표시될 수 있음을 안내했는가

모든 항목을 확인한 뒤 Release Candidate 표시를 제거하고 공개 배포하세요.
