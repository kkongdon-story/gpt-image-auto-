Cardnews Studio v4 Guide

정보형 카드뉴스 제작기 사용방법

카드 문법 텍스트를 입력하고, 스타일·비율·배경·카드별 디자인값을 조절하면 로컬 PC에서 카드뉴스 PNG를 생성합니다.

1. 실행

설치형

release/Cardnews-Studio-Setup-1.0.0.exe를 실행해 설치합니다.

무설치

release/win-unpacked/Cardnews Studio.exe를 바로 실행합니다.

개발 
npm run dev

2. 기본 제작 순서

1

스타일과 비율 선택

상단에서 스타일과 1:1, 4:5, 16:9, 4:3 비율을 고릅니다.

2

헤더와 멘션 입력

상단 헤더 라벨과 하단 계정명을 입력합니다.

3

카드 내용 작성

좌측 썸네일에서 카드를 고르고 우측 콘텐츠 탭에 라벨 문법으로 작성합니다.

4

PNG 생성

PNG 생성을 누른 뒤 경고/실패를 확인하고 PNG 또는 ZIP으로 내보냅니다.

4. 디자인 조절

전역 배경

배경 이미지 패널에서 파일을 추가하거나 Pixabay 검색을 사용합니다. 추가된 이미지는 라이브러리 id로 저장됩니다.

폰트

디자인 탭의 폰트 패널에서 ttf, otf, woff2 파일을 추가하고 선택합니다. 선택한 폰트는 미리보기와 PNG 렌더에 함께 적용됩니다.

카드별 디자인

카드 패널의 디자인 탭에서 카드별 배경, 밝기, 대비, 채도, 텍스트 크기, 굵기, 기울기, 정렬, 간격, 어둡기를 조절합니다.

레이어

카드별 디자인 탭에서 텍스트 박스, 모형, 선, 이미지를 추가합니다. X/Y/W/H 값은 카드 크기 대비 퍼센트로 입력합니다.

레일 크기

좌측 썸네일 레일과 스테이지 사이의 핸들을 드래그하면 썸네일 폭이 바뀌고 작업 상태에 저장됩니다.

품질 게이트

대비·오버플로·폰트 하한은 실패로 막고, 폰트 종류·경계 대비 같은 항목은 경고로 표시합니다.

5. 외부 AI 스타일 추가

  1. design.md 내보내기를 눌러 스타일 계약 문서를 저장합니다.
  2. JSON 구조가 궁금하면 샘플 JSON을 눌러 기본값을 먼저 확인합니다.
  3. 웹 챗봇이나 바이브코더에 design.md와 레퍼런스 이미지를 첨부합니다.
  4. 응답으로 받은 JSON 코드블록을 스타일 관리 textarea에 붙여넣습니다.
  5. JSON 스타일 등록을 누르면 상단 스타일 드롭다운의 내 스타일로 추가됩니다.

6. Pixabay 무료 이미지

Pixabay API 키를 저장하면 앱 안에서 검색하고 이미지를 바로 배경 라이브러리에 등록할 수 있습니다.

키가 없으면 같은 검색어로 Pixabay 웹페이지를 브라우저에서 열어줍니다. 내려받은 파일은 파일 추가로 등록합니다.

API 키는 렌더러 화면에 직접 노출하지 않고 main 프로세스 설정 파일에 저장됩니다.

7. CSV 대량 생성

  1. 내보내기 탭에서 CSV 템플릿을 저장합니다.
  2. output_name, header_label, footer_account, style_id, aspect_ratio, card_01, card_02는 필수입니다.
  3. 선택 컬럼으로 accent, background, dim, font_id, card_03부터 card_10까지 사용할 수 있습니다.
  4. 작성한 CSV를 불러오거나 textarea에 붙여넣고 BULK PNG를 누릅니다.
  5. 행 단위 오류는 bulk-report.json, bulk-report.csv에 남고, 유효한 행은 계속 렌더됩니다.
